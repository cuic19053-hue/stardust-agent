# Agent 链路修复与验收

本次接通三件事：用草稿的具体断言检索材料；把来源定位与判断支持关系分开；让已保存草稿、预审、补资料及重新检查形成可恢复的流程。生产部署需要同时应用新增 Supabase 迁移和服务端代码。

## 行为变化

| 场景 | 当前行为 |
| --- | --- |
| 草稿里写“已完成 1000 条实验、准确率 98.5%” | 按原句召回证据，保存断言、章节与片段的关联；不再只用章节标题配通用关键词。 |
| 前面章节很长 | 按章节轮流选择断言、分轮选择片段，避免前面章节耗尽全部召回名额。最多 80 条断言、12 个片段；完整正文仍受原有模型输入预算约束。 |
| 1200 + 1800，正文总额为 3000 | 使用 Decimal 和金额单位计算。只有显式总额和完整分项列表才核算，不拿部分费用列表直接判错。 |
| 未来实验计划和“尚未开始”的记录同时出现 | 区分计划、未完成状态和已完成结果；引用片段的选取不能绕过整章中的否定说明。 |
| 项目费用估算被模型当成学校审批规定 | 用户确认文字不等于官方政策；检查来源种类、学校、年度及来源链接。模型自行引入的无依据硬性要求被过滤。 |
| 原文引文存在，但不能证明模型的判断 | 不把逐字匹配或词汇关联当成语义蕴含。未建立可验证支持的事实判断进入 `unverified_hypotheses`，界面单列为待人工判断的 AI 线索，不进入已发现问题或自动待补项。 |
| 从聊天确认保存草稿，或应用生成章节 | 提交一次免费规则预审，记录输入快照和来源；AI 预审仍须用户主动选择。保存后的排队异常不会把已保存正文伪装成保存失败。 |
| 补资料后继续 | 报告提供章节编辑和资料确认入口；用新快照创建带 `parent_id` 的新检查。原报告及快照保留，同键重发返回原任务，旧版本不会被覆盖。 |
| 网页聊天中断 | 本地 SQLite / 云端 Supabase 保存输入和模型、工具操作结果。原请求恢复时复用已知结果；未知调用进入待核对，不自动再次请求模型。 |

## 恢复与授权边界

聊天记录通过任务完成事务只写入一次助手答复，重复提交不会重复添加消息或重新消耗原试用分配。每个运行持有有时限的租约，失效运行不能补写结果。恢复时检查实际项目资料与对话内容，输入变化后须新建一轮。

浏览器保留请求标识；恢复 BYOK 对话仍需原模型配置。请求标识不会自动带到其他设备，服务端不保存 API Key、JWT 或请求鉴权头。输入只保存当前项目的文字与来源元数据；向量保留在本次运行内存中，仍检查版本及检索授权，不进入执行记录。

云端表位于 `agent_private`，开启 RLS 并撤回客户端表权限。公开 RPC 使用 INVOKER，内部函数固定空 `search_path`，同时验证当前用户、项目归属及服务端 capability。项目删除会级联删除输入、操作和检查点。迁移允许旧版调用继续创建 v1 检查；新 worker 保留冻结的 v1 图，避免在升级时用 v2 代码解释旧检查点。

## 模型验证记录

[原始记录与冻结回放](../../server/evals/baselines/review_evidence_v2_20261118.json)保留十个已知合成回归样例的快照、请求、响应、原始报告和修复后的验收结果。模型为本机 Qwen2.5:7b；摘要、种子、上下文与输出预算见各实验 manifest。十个来源运行各执行一次真实推理，未使用生产数据、平台积分或付费云端模型。

为了核对验收层，使用相同的真实输出回放完整预审图。回放逐字核对原始模型输入和输出 schema，并校验响应摘要；输入不同时拒绝复用，不发送新的模型请求。原始实验和回放代码的哈希分别保留，不能把回放记成新推理，或用新验收结果覆盖原始响应。

在这十个已知样例上，Agent 辅助复核记录了 8 个目标命中、8 条额外写作建议和 19 条仍待人工判断的模型线索。目标均由可复核的规则检查覆盖；这些样例不能证明模型获得了额外发现能力。未解决线索未被算作正确结果。逐项判定、目标及原因在 `guard_review` 中。

这批数据已用于开发，是回归集，不是新的独立留出集。独立人工金标准和真实用户评测仍未完成；8 个命中、程序通过数、引文匹配率都不是通用准确率或学校申报资格的结论。通用语义蕴含没有被声称已自动解决，不能建立支持关系时保留人工判断。

复现冻结回放，无需 Ollama 或平台密钥：

```bash
python server/evals/review_guard_replay.py --output outputs/evals/review-v2-replay.json
```

重新发起真实本机推理需使用新输出目录，保留旧实验：

```bash
python server/evals/review_benchmark.py --arms rules,graph --output outputs/evals/review-v2-new-pilot
python server/evals/review_benchmark.py --arms rules,graph --dataset server/evals/review_holdout_cases.json --output outputs/evals/review-v2-new-additional
```
