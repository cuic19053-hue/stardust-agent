# 学生口述提取开发烟测 v1

这是Agent编写、尚未人工独立复核的合成标注集。姓名、学校和赛事为虚构；不包含真实学生档案，不作为训练集或独立验收集。

主集 `cases.json`：24例、52项标注事实，覆盖41个字段中的24个。尚未覆盖的17个字段包括完整项目描述、学生工作、英语成绩等，不能据此宣称整个字段表已通过评估。每个 `family_id` 表示独立对话家族；未来改写、对抗变体需沿用原家族并在数据划分时分组。

每例包含：

- `turns`：唯一允许进入模型的测试输入，角色与回合ID可追溯。
- `gold`：字段、记录关联、规范值、状态及最低必要原话锚点，仅供判分。
- `required_follow_up`：必须追问的字段，不要求固定问句。
- `forbidden_fields`：不能由当前输入推定或不应收集的字段；可以追问缺失值，不得先输出假值。

数值统一为字符串，缺失不输出，明确未知/拒答/否定/冲突才使用null。完整设计、局限和扩展方案见 [字段与评测方案](../../../../../docs/design/STUDENT_INTAKE_EVALUATION.md)。

运行时通过 `extraction_messages` 仅发送 `turns`，不泄露gold或判分规则。所有金标仍需人工复核；尤其是原话锚点匹配可能过严，造成语义正确但锚点不足的失败，应保留严格分数并另行记录人工裁定，不能静默修改原始基线。
