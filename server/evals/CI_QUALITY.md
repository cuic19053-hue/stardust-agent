# 必过 CI 的模型质量回归

每次 PR 和 `main` 推送都执行质量任务。口述和草稿使用固定摘要的 Qwen2.5 1.5B，在 Ollama 0.34.1 的 Linux x86_64 SSE4.2 CPU 后端重新推理。预审使用已保存的十份真实输出回放当前图，输入、输出格式或原始响应摘要不匹配时停止。任务失败会使 `Required CI` 失败。原始请求、响应、错误和逐例评分随 CI 产物 `model-quality-results` 保留。

| 评测 | 样例与执行路径 | CI 检查 |
| --- | --- | --- |
| 口述 | 八段开发集口述，经过实际的来源过滤、约束生成和候选核验 | 字段微平均 F1、整例通过数、带正确引文的命中数及禁用字段 |
| 草稿 | 两段大创草稿，使用工作台 Draft → Critic 工作流的一轮生成与审稿 | 逐例保留经实测命中的事实与计划表达，新增已定义的编造、绝对化数字或复述提示词即失败 |
| 预审 | 十个已归档合成项目的真实模型响应，用当前预审图重放，由原逐条判定核对问题 | 目标命中、漏报、误报和未复核的公开意见 |

固定样例与阈值记录在 [ci_quality.json](baselines/ci_quality.json)。字段 F1 要求字段、记录编号、值和状态同时匹配。整例还要求证据和必要追问通过。草稿检测采用明确的词句断言，范围是两个已知场景的事实保留、计划状态及已列问题。预审的真实输出归档与公开意见判定见 [原验收记录](../../docs/reports/AGENT_REVIEW_LOOP_2026-11-18.md)。

首轮实测口述 F1 为 **47.62%**，整例通过 **2/8**，带正确引文的命中 **5** 项，禁用字段 **0** 项。草稿保留了 **6/6** 项事实与计划表述，但两例都存在已知问题。积水草稿补写了未提供的观测指标，标本卡草稿补写了时间或进度，并复述了部分提示词。门禁按例保留六条已通过的检查，并阻止新增定义内的问题。预审回放命中 **8/8** 个目标，公开意见中误报和未复核意见均为 **0**。

## 2026-11-27 口述核验改进

修改浏览器和工作台共用的来源核验后，同一模型用相同请求重新推理。八条合成口述的样例、评分脚本和门禁阈值均未修改。实测字段 F1 从 **47.62% 升到 100.00%**，整例从 **2/8 升到 8/8**，有正确引文的字段从 **5 项增至 15 项**，两次禁用字段均为 0。

| 首轮未通过的样例 | 首轮失败点 | 改进后命中 |
| --- | --- | ---: |
| 自我介绍 | 模型只提姓名，漏掉同一段明确陈述的学校、专业和年级 | 4/4 |
| 绩点与满分 | 模型只提绩点，漏掉紧邻的满分，还生成了重复追问 | 2/2 |
| 大创计划 | 模型只提申请类型，漏掉紧邻的计划成果 | 2/2 |
| 预算和人数 | 预算保留「万元」字符串，团队人数漏提 | 2/2 |
| 国家奖学金 | 模型的整句引文跨过收入遮罩，候选无法通过原话校验 | 2/2 |
| 否认科研经历 | 模型把 `negated` 当作正文字符串，明确否认被过滤 | 1/1 |

新的候选按可核对的原话分项归属，保留计划、估算和明确否认的状态。跨遮罩的引文只影响相应候选，其他有独立依据的字段可继续展示。学生仍需核对后手动确认入档。

样例由 Agent 编写，覆盖已知回归。结果描述所用本地模型与这些样例，独立人工评测、正式模板验收以及生产模型质量另有各自的验证范围。

## 本地复现

启动 Ollama 0.34.1 后下载 `qwen2.5:1.5b`。评测连接回环地址，校验 Ollama 版本及模型摘要，使用固定种子、温度 0 和 CPU 推理。每次使用新的输出目录。

基线在 macOS 上实测并用 CI 指定的 Linux x86_64 SSE4.2 后端复核。其他 CPU 后端会产生文本差异。一次 Linux ARM64 复测的口述 F1 为 40.00%，整例通过 1/8，触发了现有门禁。

```bash
uv sync --locked --extra review
ollama pull qwen2.5:1.5b
uv run --no-sync python -m server.evals.quality_gate --output outputs/quality-recheck
```

需要更新样例或基线时，在新目录加 `--measure-only` 采集候选结果。比较逐例变化和失败原文，在 PR 说明更改理由，并同步更新样例摘要及阈值。CI 始终使用带阈值的默认模式。评测没有平台积分或外部模型密钥依赖。
